# 数模工坊 · 使用与激活指南

---

## 一、先免费试 2 小时

打开软件就能用，**不需要注册，不需要登录**。

右上角会显示剩余时间，像这样：

```
体验中 1:23:45
```

**这 2 小时里功能是完整的**——四类材料提交、五步流程、出图、出论文都能跑。

> 剩不到 15 分钟时，那个倒计时会变成黄色提醒你。

⚠️ **体验版产出的论文和图表会带一行水印**（页面中间的斜排淡灰字、图表右下角小字）。
**激活之后就不带了**，产出的文件是干净的。

## 二、先选赛事：顶栏「赛事」面板

点顶栏的 **「赛事」** 按钮，会展开一张赛事日历：

- **每场比赛的官方时间**（开始 / 结束 / 报名截止）
- **状态徽标**：报名中 · 进行中 · 已结束 · 待公布
- **倒计时**：报名中的赛事会显示「距开赛 43 天」，按钮上也会直接显示天数
- 点「官网」用系统浏览器打开赛事主页；点「设为当前赛事」切换你正在准备的比赛

**为什么要选赛事？** 两件事跟着它走：

1. **成稿口径**：论文按该赛事的篇幅与版式规范写（国赛约 30 页、华为杯 50 页以上、美赛/亚太约 22 页）
2. **解锁范围**：卡密是按赛事签发的 —— 买了国赛卡，就只能选国赛；全能包解锁全部

> 现在（2026-10）正在报名的是 **数维杯秋季赛**（11-20 开赛），软件会自动把它设为当前赛事。
> 国赛、华为杯、亚太赛的 2026 届已经结束；美赛 2027 的时间官方还没公布，面板上显示「待公布」。

## 三、AI 工具使用声明（重要，别漏）

**2026 年起这是硬性要求**：国赛《人工智能工具使用规定（2026 年试行）》规定，
论文**参考文献之前**必须有一节「AI 工具使用声明」，二选一：

- 没用 AI：写「本参赛队在竞赛过程中未使用任何 AI 工具。」
- 用了 AI：写「…使用了 AI 工具，主要用于【用途】，详细使用情况见支撑材料。」

用了 AI 的还要在支撑材料里附《AI工具使用详情.pdf》，写清四项：工具名称版本、
使用目的和环节、主要提示方式、人工采纳与核验情况。

**软件会帮你做**：

1. 成稿时自动把声明插到**参考文献之前**（位置错了自检会报出来）
2. 赛事面板里点「生成 AI 声明草稿」，按当前赛事规定生成到工作区 `reports/`

> 🔴 **声明内容必须你自己核实。** 软件**不会替你编**「用了什么工具、用来做什么」——
> 未填的地方会留成 `【请填写…】`，自检也会把它当问题报出来。
> **虚假声明按规定是要取消评奖资格的**，所以请照实填。

> 华为杯允许用 AI 但要求所有引用（含程序、AI 产品）注明来源；美赛要在报告里写
> Report on Use of AI Tools。软件的措辞已按三个赛事分别内置。

## 四、体验结束后怎么激活

时间用完，界面会自动弹出激活页，分三步：

### 第 1 步 · 复制你的机器码

界面上会显示一串像这样的字符：

```
7E84-2A70-F998-6EB7
```

点右边的「复制」按钮。

**这串码是这台电脑的唯一标识**，卡密就是绑着它签发的——所以**别复制到别的电脑上用**。

### 第 2 步 · 扫码加微信

界面上有**微信二维码**，扫一下加我（微信号 `xhxc287`）。

加上之后，**把第 1 步复制的机器码发给我**，并说明你要买。

**付款也在微信里进行** —— 我会把收款码发给你，付完直接给你卡密。有什么问题也能当场问。

### 第 3 步 · 粘贴卡密

客服会发给你一段**很长的字符**（200 多个字符），像这样：

```
eyJjYXJkIjoiTUNNLTIwMjYtMDAwMSIsIm1hY2hpbmUiOiI3RTg0MkE3...
```

**完整复制**，粘贴到界面上的输入框，点「解锁」。

> ⚠️ **一定要复制完整**。这段字符很长，在微信里手动拖选容易漏掉尾巴。
> 建议**长按 → 全选 → 复制**。

## 五、换电脑了怎么办

**卡密和电脑是绑定的，换机后原卡失效。**

联系客服，把**新电脑的机器码**发过去，客服会给你重新签发一张。

> 一般每张卡有免费的换机次数，具体政策问客服。

## 六、改错了想重来（回滚）

**每一轮对话开始前，程序会自动给工作区存一份快照。** 想退回去的时候：

1. 把鼠标移到你想退回的那条**提问**上（不必是最新的那条）
2. 点出现的「回滚到这里」
3. 可以顺手把问题改一下，再点「重发」

点下去会发生两件事：

- **对话** —— 这条之后的问答全部作废
- **工作区** —— 文件**整体还原**到这条提问发出前的状态：
  之后新生成的文件消失、被改写的文件变回原样、被删掉的文件回来

> 还原前的工作区**不会直接删掉**，会整份挪进 `工作区/_backup/rollback-<时间>/`。
> 万一退错了，去那个目录把文件拷回来就行。

**存多少份？** 默认保留最近 **8 次**，更早的自动清理。
工作区超过 400MB 时那一次会跳过快照（避免把磁盘撑爆）。

## 七、常见问题

**Q：卡密提示无效？**

按顺序检查：

1. **是不是没复制全？** 卡密有 200 多个字符，这是最常见的原因。
   重新长按 → 全选 → 复制，再粘一次。
2. **是不是换了电脑？** 换机后必须找客服重新签发。
3. **是不是过期了？** 问客服确认有效期。
4. 都不对，就把**机器码 + 卡密**一起发给客服。

**Q：提示「当前赛事未解锁」？**

你的卡密是**按赛事签发**的。比如买的是国赛卡，却在赛事面板里选了华为杯，就会拦下来。

两种解决办法：

1. **切到已解锁的赛事** —— 打开顶栏「赛事」面板，选你买的那场
2. **补差价买这场** —— 找客服，或直接买**全能包**（解锁全部赛事）

> 提示框里会写清楚「这场多少钱、全能包多少钱」。

**Q：提示「授权已到期」？**

和「体验已结束」不是一回事 —— 这表示你**买过**，但卡密过了有效期（比如买的是"本届比赛"卡）。
联系客服续期或购买新卡即可，机器码不用重发。

**Q：一张卡能用在几个赛事上？**

看你买的是哪种：

- **单赛事卡**（¥29–79）：只能在那一场用
- **全能包**（¥168）：解锁全部赛事，包括以后新增的

**Q：机器码显示「读取失败」或者一串奇怪的字符？**

极少数电脑读不到硬件序列号。**把界面上的内容原样截图发给客服**，客服会处理。

**Q：重装系统后要重新激活吗？**

**一般不用。** 机器码取的是 CPU、主板、硬盘的序列号，重装系统不影响。

但如果你的电脑本来就读不到这些信息（见上一条），重装可能导致机器码变化。

**Q：把系统时间调回去能多用一会儿吗？**

**不能。** 软件记录的是「首次运行时间」，把时钟倒回去，剩余时间不会变多。

**Q：双击后闪一下就没了 / 窗口打不开？**

少数虚拟机、远程桌面、或者显卡驱动异常的电脑上会出现。试这个：

1. 关掉软件
2. 按 `Win + R`，输入 `cmd`，回车
3. 在黑窗口里依次输入这两行（每行回车一次）：

   ```
   set MCM_NO_GPU=1
   "%LOCALAPPDATA%\Programs\数模工坊\数模工坊.exe"
   ```

   > 便携版请把第二行的路径换成你自己解压的位置。

这样会用**软件渲染**启动，绕开显卡问题。确认能用之后，可以做个 `.bat` 文件省得每次输。

**Q：能装到几台电脑上？**

**一张卡一台电脑。** 这是卡密的机制决定的——它绑定了你付款时提供的那台机器。

**Q：换了显卡/加了内存要重新激活吗？**

**不用。** 机器码只看 CPU、主板、硬盘序列号，换显卡加内存都不影响。

**Q：换了硬盘呢？**

**要重新激活。** 系统盘序列号是机器码的一部分。联系客服重新签发。

## 八、数据在哪

软件的工作区默认在：

```
C:\Users\<你的用户名>\Documents\数模工坊工作区
```

里面按 `input/`、`code/`、`figures/`、`results/`、`reports/` 分好类。
**卸载软件不会删这个目录**，你的成果都在。
