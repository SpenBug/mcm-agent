# 数据图规范 · mcm-figure

本文件管**数据图**：由数值算出来的图。
**非数据图**（技术路线图 / 子问题流程图 / 数据处理流程 / 模型结构图 / 指标体系图 / 决策树）
走 `mcm-diagram`（draw.io 竞赛模式）——那类图**不要**用 Matplotlib 手绘。

---

## 什么时候用

- 论文正文 / 附录里的数据图，需要**印刷级**质量
- 结果可视化：对比、趋势、分布、相关性、灵敏度
- 把已有图改成统一风格（同一篇论文里图与图之间要一致）

## 什么时候不用

- **非数据图** → `mcm-diagram`
- 交互式图表 / 网页可视化（Plotly、ECharts）
- 只在探索阶段临时看一眼、不打算进论文的图

---

## 设计令牌（唯一真源）

色板与字号**沿用本系列的视觉系统**（`风格规范/template/src/remotion/theme.ts`）。
视频用亮版，**论文图用深版**——深版在纸面对比度才够。

### 色板

| 语义 | 亮版（视频用） | **深版（论文用）** | 建议用途 |
|---|---|---|---|
| 主蓝 | `#4C8DFF` | **`#2563EB`** | 主方案 / 基准组 |
| 青 | `#22D3EE` | **`#0E8FA6`** | 对照方案 / 次要序列 |
| 绿 | `#34D399` | **`#0F9B6C`** | 达标 / 正收益 |
| 紫 | `#A78BFA` | **`#7C3AED`** | 第三序列 / 消融 |
| 橙 | `#FB923C` | **`#C2410C`** | 注意 / 中间态 |
| 琥珀 | `#FFB020` | **`#B45309`** | 警告 |
| 红 | `#FF3B5C` | **`#C41F3C`** | 失败 / 负收益 / 危险 |
| 黄 | `#FFD54A` | **`#D97706`** | 强调标注 |

**正文与坐标轴文字**：`#08101F`（深墨）· 次要刻度：`#6B7796`
**网格线**：`#E3E7EF`（极浅）· **坐标轴线**：`#C3CDE8`

### 语义映射（沿用视频的 Tone 体系）

```
normal（默认 / 通过） → #0E8FA6 青
warn  （需注意）      → #D97706 黄
danger（失败 / 危险）  → #C41F3C 红
```

**这三条是硬约定**：同一篇论文里，青=正常、黄=注意、红=危险，不要混用。

### 字号（按论文正文小四 = 12pt 反推）

| 元素 | 字号 | 字重 |
|---|---|---|
| 轴标题 | 10.5pt | regular |
| 刻度标签 | 9.5pt | regular |
| 图例 | 9.5pt | regular |
| 面板编号 (a)(b)(c) | 11pt | **bold** |
| 图内标注 | 9pt | regular |

> 图注（caption）在正文里排版，**不要画进图里**。

### 中文字体

```python
plt.rcParams["font.sans-serif"] = ["Noto Sans SC", "Source Han Sans SC",
                                   "Microsoft YaHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False   # 负号不显示成方块
```

## 三条硬约束

1. **一图一结论。** 每张图只回答一个问题。回答不了就问自己：这张图去掉行不行？
2. **数值必须来自实际运行结果。** 禁止编造、禁止"示意性"画一条好看的曲线。
   图上每个数字都要能追溯到 `results/` 里的某个文件。
3. **同篇论文的图必须同风格。** 字号、配色、线宽、网格，全套一致。

## 出图前后必须过的门禁

**出图前**：
- [ ] 数据来自 `results/` 的真实运行结果，不是手写的
- [ ] 想清楚这张图要回答什么问题（一句话写下来）

**出图后**：
- [ ] 中文字体正常显示（没有方块、没有乱码）
- [ ] 负号正常显示（`axes.unicode_minus=False` 已设）
- [ ] 配色用的是**深版**，不是视频亮版
- [ ] 同一论文里其他图的字号 / 线宽 / 配色一致
- [ ] 导出同时有 `.pdf`（矢量，进论文）和 `.png`（300dpi，预览用）
- [ ] 图里没有超出画布的元素（标注被裁掉是最常见的翻车点）

**任一项没过 → 不算完成。**

## 命名约定

```
figures/
  raw_qN_*.pdf        原始数据图（未加工）
  process_qN_*.pdf    数据处理过程图
  result_qN_*.pdf     结果图（论文正文引用）
```

`qN` = 第 N 问。同一问的多张图加序号：`result_q1_1.pdf`、`result_q1_2.pdf`。

> **不要**用 `fig_roadmap` 这类名字——那是 `mcm-diagram` 的非数据图命名，两套不要混。
