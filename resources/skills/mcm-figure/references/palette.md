## 怎么给 N 个序列配色

按**语义**选，不按顺序随便取。

### 2 个序列（最常见的对比）
```
主方案  #2563EB 蓝
对照    #0E8FA6 青
```

### 3 个序列
```
#2563EB 蓝   →  #0E8FA6 青   →  #7C3AED 紫
```

### 4 个序列
```
#2563EB 蓝   →  #0E8FA6 青   →  #7C3AED 紫   →  #C2410C 橙
```

### 有「好坏」含义时（不要按上面的顺序）
```
好  #0F9B6C 绿      中  #D97706 黄      差  #C41F3C 红
```

> **判断标准**：图里有"更好/更差"的含义吗？
> 有 → 用绿/黄/红。没有（比如只是三组平行实验）→ 用蓝/青/紫。

## 对比度规则（印刷级）

论文图会**黑白打印**，也会被**色觉障碍读者**看到。所以：

1. **不靠颜色单独区分序列** —— 再叠一层视觉线索：
   - 柱状图：不同的填充纹理（实心 / 斜线 / 点阵）
   - 折线图：不同的线型（实线 / 虚线 / 点划线）+ 不同的点标记（○ / □ / △）
2. **相邻序列的明度差 ≥ 25%** —— 灰阶打印时才分得开。
   上面给的顺序（蓝→青→紫→橙）已按明度拉开，直接用即可。
3. **深色块上的文字用 `#FFFFFF`，浅色块上用 `#08101F`。**
   不要用中灰——那是可读性最差的选择。
4. **不要用纯黑 `#000000`** 画线或写正文，用 `#08101F`（深墨，比纯黑柔和）。

## 常用元素约定

| 元素 | 约定 |
|---|---|
| 网格 | 只留**横向**细网格 `#E3E7EF`，线宽 0.6；不要竖网格，不要网格底色 |
| 边框 | 只留**左 + 下**两条轴，颜色 `#C3CDE8`，线宽 0.8；上、右去掉 |
| 刻度 | 朝内，长度 3，颜色 `#C3CDE8` |
| 折线 | 线宽 1.6，点标记大小 4，标记边宽 0.8 |
| 柱状 | 无边框，柱宽 0.7；分组时组内间距 0.1 |
| 误差棒 | 颜色比主色深一档，`capsize=3`，线宽 1 |
| 图例 | 无边框、无底色，字号 9.5，放在不压数据的位置 |
| 高亮 | 要强调的点用 `#D97706` 加一圈描边，而不是把整条线加粗 |

## 直接 import 用

`scripts/mcm_style.py` 是配套的 matplotlib 样式模块，封装了上面所有约定：

```python
import sys; sys.path.insert(0, "skills/mcm-figure/scripts")
import mcm_style

mcm_style.apply()                       # 一次性套用全局 rcParams
fig, ax = plt.subplots(figsize=(6.3, 4.0))
ax.bar(x, y, color=mcm_style.C["blue"])
```

模块里可直接取的常量：

```python
mcm_style.C["blue"]     # '#2563EB'   深版
mcm_style.C["cyan"]     # '#0E8FA6'
mcm_style.C["green"]    # '#0F9B6C'
mcm_style.C["red"]      # '#C41F3C'
mcm_style.SEQ2 / SEQ3 / SEQ4       # 预设序列色序
mcm_style.TONE["normal"]           # 语气色
mcm_style.save(fig, "figures/result_q1_1")   # 同时出 pdf + png
```
