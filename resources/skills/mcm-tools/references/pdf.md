# 读 PDF（赛题 / 规范）

```bash
python "%MCM_SKILL_ROOT%/mcm-tools/scripts/mcm_io.py" pdf input/赛题.pdf
python "%MCM_SKILL_ROOT%/mcm-tools/scripts/mcm_io.py" pdf input/格式规范.pdf --pages 1-4
python "%MCM_SKILL_ROOT%/mcm-tools/scripts/mcm_io.py" pdf input/赛题.pdf --pages 2 --json
```

---

## 什么时候用

- 客户拖进来的**赛题**（PDF）
- 客户给的**格式规范 / 参赛须知 / 提交说明**（PDF）
- 论文模板的说明文档

## 用的时候注意

### 1. 扫描件抽不出文本

如果输出是「（该页无可抽取文本，可能是扫描件/图片）」，说明这页是**图片**。
不要假装读到了内容——**如实告诉客户这一页需要他自己确认**，或者请他提供文字版。

### 2. 按页定位

规范里常写「附件2 第 3 条」，用 `--pages 3` 精确定位，比全文读一遍再找省事。

### 3. 大文件先看目录页

先读第 1 页确认是不是要找的文件，再读需要的部分。整本规范没必要全读进来。

### 4. 表格会散

PDF 里的表格抽出来会变成一堆空格分隔的文字，**行列关系会丢**。
如果规范里有表格（比如字号对照表），抽出来后要**人工核对一遍结构**，不要直接当数据用。

---

## 输出格式

默认人类可读（带页码分隔线）。需要机器处理时加 `--json`：

```json
{"path": "...", "total_pages": 12,
 "pages": [{"page": 1, "text": "..."}]}
```

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 参数错误 / 缺 pypdf |
| 2 | 文件不存在或读取失败 |

---

## 读进来的东西怎么用

读到的**规范条款**要进 `reports/规则卡.md`，逐条附原文摘录 + 出处 + 核对日期。
读到的**题目**用来拆子问题，产出 `题目分析报告.md`。

> ⚠️ 规范条款**逐届修订**。读到的规范如果是往届的，在规则卡里标注
> 「本卡基于 <年份> 届，当届须重新核对」，并提醒客户。
