# 提交前自检 · 十二闸

> **用法**：交稿前逐项打勾。**按本表顺序查，不要从论文第一页顺往下翻**——
> 致命闸是「整份作废」级，而它偏偏住在你最后写、最少检查的地方。
>
> **条款逐届修订，不得沿用往届。** 下表「华为杯 2026 实测」列是**参考实现**，
> 用于说明每一闸该查什么；当届的具体数值必须以客户提供的**当届官方原件**为准。

---

## 第一级 · 致命闸（错了不是扣分，是整份作废）

### ☐ G-01 匿名性

**查三个地方：最后一页的致谢 · 附录代码的注释 · 截图里的文件路径**

| ☐ | 检查项 |
|---|---|
| ☐ | 全文无学校 / 学院 / 单位名称 |
| ☐ | 无队员姓名、无参赛队号 |
| ☐ | 截图与代码中的路径已脱敏（`C:\Users\张三\...` 这类会暴露身份） |
| ☐ | 图注、表注、页脚脚注里也没有身份信息 |

> **华为杯 2026 实测**
> 附件2：「论文中不能有任何可能显示答题人身份的标志。」
> 开赛公告：「除首页外其他页面中不允许出现单位、参赛人员姓名、队伍编号等信息，**否则视为违规，论文无效**。」

---

### ☐ G-07 人工智能合规

| ☐ | 检查项 |
|---|---|
| ☐ | 正文文字已用**本队自己的语言**重述，无直接粘贴 AI 输出 |
| ☐ | 无法确认来源的模型 / 公式：已标注并在参考文献列出工具**名称、版本/型号、开发机构/公司、版本发布日期** |
| ☐ | **已删除**无推导过程、无引用标识、且无法确认来源的模型与公式 |
| ☐ | 数据分析结果的前导或后面已加注释，标明 AI 工具四要素 |
| ☐ | 程序**前面**已加注释：本程序及代码是在人工智能工具辅助下完成 + 四要素 |
| ☐ | 论文末尾以附录形式披露所用 AI 软件、输入及对输出的后续处理策略 |

> **华为杯 2026 实测**（附件4）
> 第 2 条：「最终呈现在解答中的文字，必须使用参赛队自身的语言进行表述。」
> 第 3 条：「对于无推导过程、无引用标识、且无法确认来源的所谓模型及公式**一律不予认可**。」
> 第 7 条：「违反上述规定的参赛作品，被视为违反竞赛规则，**取消其评奖资格**。」

## 第二级 · 格式闸（错一项扣一处的分，且容易被判「不规范」）

### ☐ G-02 页眉与页码

| ☐ | 检查项 |
|---|---|
| ☐ | 全篇**无页眉**（含模板残留的页眉，**注意分节符后可能重新出现**） |
| ☐ | 页码从**摘要页**开始，不是从正文开始 |
| ☐ | 页码位于**每页页脚中部** |
| ☐ | 阿拉伯数字从「1」开始**连续**编号 |
| ☐ | 封皮页未被计入页码 |

> **华为杯 2026 实测**：附件2「论文不能有页眉。」「论文从摘要页开始编写页码，页码必须位于每页页脚中部，用阿拉伯数字从"1"开始连续编号。」

---

### ☐ G-03 封皮与图标

| ☐ | 检查项 |
|---|---|
| ☐ | 首页为**官方模板封皮**，未删除、未替换成自制封面 |
| ☐ | 封皮上的 logo 图标**未被替换** |
| ☐ | 封皮上学校 / 参赛队号 / 队员姓名已填全 |

> **华为杯 2026 实测**：开赛公告「论文必须按附件 3 模板进行编写，并确保提交的论文的首页为封皮（不可删除，包含团队相关信息，且 4 个 logo 图标不能替换），第二页起为摘要页和正文页。」
> 实操核验法：官方模板 `word/media/` 内正好 4 个图片文件，可据此确认没被替换。

---

### ☐ G-04 字号与行距

| ☐ | 检查项 |
|---|---|
| ☐ | 论文题目：**三号黑体，居中** |
| ☐ | 一级标题：**四号黑体，居中** |
| ☐ | 其他汉字**一律**小四号宋体（含**表格内文字、图注、表注、公式后的说明**） |
| ☐ | 行距：**单倍行距** |

> **华为杯 2026 实测**：附件2「论文题目用三号黑体字、一级标题用四号黑体字，并居中。论文中其他汉字一律采用小四号宋体字，行距用单倍行距。」
> ⚠️ 最常见的漏点是**表内文字和图注**——正文改了字号，表格忘了改。

---

### ☐ G-05 摘要

| ☐ | 检查项 |
|---|---|
| ☐ | 六要素齐全：**建模思路 / 主要方法 / 模型 / 结果与结论 / 创新点 / 关键词** |
| ☐ | 篇幅**不超过两页** |
| ☐ | **未译成英文**（官方明写无需，白占正文篇幅） |
| ☐ | 摘要页上同时有论文题目、摘要、关键词 |
| ☐ | 正文从摘要页的**下一页**开始 |

> **华为杯 2026 实测**：附件2「摘要应简明扼要，需包含：建模思路、主要方法、模型、结果与结论、创新点、关键词等，请认真书写（**注意篇幅一般不超过两页，且无需译成英文**）。评阅时对摘要和论文都会审阅。」

---

### ☐ G-06 参考文献

| ☐ | 检查项 |
|---|---|
| ☐ | 按**正文中的引用次序**编号列出 |
| ☐ | 正文引用处用**方括号**标示，如 [1][3] |
| ☐ | 书籍条目**指出页码** |
| ☐ | **引用程序已注明来源** |
| ☐ | 三种句式的**标点位置照抄**，未被文献管理工具导出格式替换 |

> **华为杯 2026 实测**：附件2 三种表述方式（**标点不可改**）
> 书籍：`[编号] 作者，书名，出版地：出版社，起止页码，出版年。`
> 期刊：`[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。`
> 网络：`[编号] 作者，资源标题，网址，访问时间（年月日）。`
> ⚠️ 用 Zotero / EndNote 导出常把逗号换成句点，**必须逐条对照官方句式**。

## 第三级 · 提交闸（技术性失误，但会直接导致交不上）

### ☐ G-08 提交物与时间窗

| ☐ | 检查项 |
|---|---|
| ☐ | **先确认论文是终稿，再生成识别码** |
| ☐ | 识别码生成后**未再改动 PDF 一个字**（改了系统会传不上去） |
| ☐ | PDF **不得压缩** |
| ☐ | 命名符合「试题编号 + 队伍编号」规则 |
| ☐ | 程序附件为指定格式，且**不超过体积上限** |
| ☐ | 系统内提交成功，按钮右侧出现**绿色对号** |
| ☐ | 未在竞赛期间将论文进行网上查重 |

> **华为杯 2026 实测**（附件1 §2.5）
> ① 提交论文识别码：9/26 12:00 → 9/27 12:00，用 MD5 校验工具对**最终 PDF** 生成
> ② 上传论文 PDF：9/27 14:00 → 9/28 24:00，**不得压缩**，命名 `A26000010001.pdf`
> ③ 上传程序附件：9/29 08:00 → 9/30 24:00，`.rar`，同名，**≤ 50 MB**
> 「MD5 识别码与提交论文对应，一旦提交 MD5 识别码，相应论文禁止修改，否则论文将无法成功上传。」
> **兜底通道**：识别码环节遇网络故障，把失败截图 + MD5 码 + PDF + 队伍编号发至官方邮箱，超时无效。

## 一页速查

```
致命  G-01 匿名性      致谢 / 代码注释 / 截图路径        → 论文无效
致命  G-07 AI 合规     自身语言 / 四要素 / 删除无来源公式  → 取消评奖资格
格式  G-02 页眉页码    无页眉；从摘要页、页脚中部、1 起连续
格式  G-03 封皮图标    封皮不删；logo 不换
格式  G-04 字号行距    题三号黑体 / 一级四号黑体 / 一律小四宋 / 单倍
格式  G-05 摘要        六要素；≤2 页；无需译英文
格式  G-06 参考文献    按引用次序；方括号；书籍页码；程序注明；标点照抄
提交  G-08 提交物      先定终稿再生码；生码后一字不改
```

## 自检报告的写法

产出 `reports/自检报告.md`，**逐闸列结论，不要只写「已检查」**：

```markdown
# 提交前自检报告

| 闸 | 结论 | 证据 | 备注 |
|---|---|---|---|
| G-01 匿名性 | PASS | 全文检索「大学/学院/队号」0 命中；`code/` 内路径已替换为 `./data/` | — |
| G-04 字号行距 | FAIL → 已修 | 表 3 内文字为五号，规范要求小四 | 已改为小四宋，重跑通过 |
| G-08 提交物 | 待办 | 识别码未生成（需客户在终稿确认后自行生成） | 已提醒 |
```

**致命闸不通过时，不得声称交付完成。**
