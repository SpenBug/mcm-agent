# 模板 task-bands · 任务带技术路线图

任务一…任务N 纵向条带：珊瑚红实线圆角外框，左右各一条珊瑚红竖签（白字：左=任务N，
右=本任务产出）；带内钢蓝虚线圆角子区并排（深蓝标题居中 + 橙沙色流程盒行，行间细黑
箭头）；带间黑色粗箭头推进。子区可带 `"w"` 权重控制相对宽度（默认等分）。画布宽 1080。

渲染：`python3 scripts/task_bands.py content.json -o out.drawio`（`--check` 只校验）。

- [一、语义约定](#一语义约定)
- [二、字数预算](#二字数预算)

## 一、语义约定

- **带的顺序＝任务的推进顺序**，黑箭头表示"上一任务产出喂给下一任务"。
- **任务签（左）写"任务N"**；**阶段签（右）写该任务的产出/定位**（如"特征提取""迁移诊断"），
  是整条带的收束语，不要写成流水账。
- **子区是带内的并列工作模块**（如"数据处理 / 特征构造 / 特征分析"），横向并排、互不连接；
  子区内部行与行是先后关系（细灰下箭头）。
- 同一条带的子区高度取最高者对齐；子区行数差异大时视觉不平衡，尽量均衡。

## 二、字数预算

字号：盒 11、子区标题 12、竖签 13–14；行高＝字号+3。

| 槽位 | 宽度 | 预算 |
|---|---|---|
| 任务签 | 56×带高 | 2–4 字（竖排） |
| 阶段签 | 76×带高 | ≤6 字（竖排，13px） |
| 子区标题 `title` | 子区宽−16 | 3 子区时 ≤22 汉字 |
| 子区内盒（1 盒/行） | 子区宽−36 | 3 子区时 ≤24 汉字 |
| 子区内盒（2 盒/行） | 约 127 | ≤10 汉字 |

数量区间：`bands` 2–5；每带 `subs` 1–4；每子区 `rows` 1–5；每行 1–3 盒（盒宽 ≥60px，
低于即 `sys.exit`）。
