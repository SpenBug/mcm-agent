# 模板 part-zones · 章节分区路线图

第一部分…第N部分：彩色圆角虚线分区 + 框内同色章节标题 + 浅色流程盒行 +
行下可挂说明小字；分区之间绿色双箭头（>>）推进。半宽分区成对并排。画布宽 1080。

渲染：`python3 scripts/part_zones.py content.json -o out.drawio`（`--check` 只校验）。

- [一、语义约定](#一语义约定)
- [二、字数预算](#二字数预算)

## 一、语义约定

- **分区的顺序＝研究开展的顺序**；连续两个 `layout: "half"` 并排成一行（同排之间双箭头东向），
  否则双箭头南向。
- **`accent` 五选一**：`teal / green / orange / red / blue`，分区框、标题、盒描边同色；
  相邻分区换色，不要相邻同色。
- **`notes` 是图表/结果的说明小字**（如"XGBoost调参学习曲线 · ROC曲线"），挂在行下方，
  只写结论性短句，不要写成第二层流程。
- 标题写"第X部分：……"；这是**章节级**路线图，盒里写该章节做什么，不写方法参数细节。

## 二、字数预算

字号：分区标题 17、盒 13、注释 11；行高＝字号+3。

| 槽位 | 宽度 | 预算 |
|---|---|---|
| 分区标题 | 整行 1016 / 半宽 478 | ≤59 / ≤28 汉字 |
| 盒（整行 1 盒） | 1000 | ≤76 汉字 |
| 盒（整行 4 盒） | 233 | ≤17 汉字 |
| 盒（半宽 1 盒） | 454 | ≤34 汉字 |
| `notes` 每行 | 分区宽−32 | 整行 ≤94 / 半宽 ≤44 半角折半 |

数量区间：`zones` 2–6；每区 `rows` 1–4；每行 1–4 盒；`notes` 0–3 行（超限 `sys.exit`）。
