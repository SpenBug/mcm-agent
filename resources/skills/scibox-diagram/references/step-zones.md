# 模板 step-zones · step 分区流程图

step1…stepN 横排：彩色圆角虚线分区 + 框顶同色 step 标题 + 内部流程盒行
（行间细灰箭头，可标 emph 实色强调盒）；分区之间蓝白粗块箭头推进。画布宽 1080。

渲染：`python3 scripts/step_zones.py content.json -o out.drawio`（`--check` 只校验）。

- [一、语义约定](#一语义约定)
- [二、字数预算](#二字数预算)

## 一、语义约定

- **分区的顺序＝方法步骤顺序**（step1 → step2 → …），蓝块箭头单向推进，不要画回流。
- **标题写"stepN：……"**，一个分区就是一个大步骤；分区内部行是子步骤先后关系。
- **同一行的盒是并列分支**（如"图片数据 / 文本评论"两类数据源），行间才是先后。
- **`emph: true`** 实色强调盒，标该步骤的**核心机制/公式环节**；每个分区最多一处。
- 配色按分区顺序自动循环（青→橙→红→蓝），相邻分区天然异色。

## 二、字数预算

字号：分区标题 15、盒 12；行高＝字号+3。三分区时区宽 308。

| 槽位 | 宽度 | 预算 |
|---|---|---|
| 分区标题 | 292 | ≤19 汉字（单行） |
| 盒（1 盒/行） | 260 | ≤21 汉字 |
| 盒（2 盒/行） | 129 | ≤10 汉字 |
| 盒（3 盒/行） | 80 | ≤6 汉字 |

数量区间：`zones` 2–4；每区 `rows` 1–6；每行 1–3 盒（区宽 <240px 即 `sys.exit`）。
