# 模板 trihead-flow · 三栏绿头流程图

2–4 栏横排：每栏绿实色标题栏 + 浅绿栏体，栏内自上而下流程盒（蓝系三档深浅），
支持橙虚线特征组（组标题 + 小盒阵列 + 两侧竖排标签）与底部图表占位；
栏间黑色粗箭头推进。画布宽 1080。

渲染：`python3 scripts/trihead_flow.py content.json -o out.drawio`（`--check` 只校验）。

- [一、语义约定](#一语义约定)
- [二、字数预算](#二字数预算)

## 一、语义约定

- **栏的顺序＝流水线顺序**，黑箭头表示"上一栏产出喂给下一栏"。
- **盒是"做什么"，组是"一类并列要素"**：连续叙述的步骤用普通盒；
  同一母体下并列的枚举（如 16 种时/频域特征）才用 `group`，别把组当第二条流水线。
- **盒色三档**：`deep`（起点/数据源）、`mid`（默认处理）、`light`（末端/输出）；
  不指定时按 mid→light 自动交替。起点标 deep、终点前一步保持 light，深浅才有语义。
- **`chart` 是图表占位**：写图名（如"样本时域波形与指标图"），出图时替换成真实图片。
- 组的 `left/right` 是竖排归类签（如"时域特征/频域特征"），≤4 字才放得下。

## 二、字数预算

字号：栏题 16、盒 12、组内 11；行高＝字号+3。三栏时栏宽 304。

| 槽位 | 宽度 | 预算 |
|---|---|---|
| 栏题 `title` | 296 | ≤18 汉字 |
| 普通盒 | 268 | ≤22 汉字 |
| 组标题 | 135 | ≤12 汉字 |
| 组小盒（3 列） | 56 | ≤5 汉字 |
| 组侧签（竖排） | 高 62 | ≤4 字 |
| `chart` 图名 | 268 | ≤24 汉字 |

数量区间：`columns` 2–4；每栏 `items` 2–7；组内 `boxes` 3–9（3 列排布，超限 `sys.exit`）。
